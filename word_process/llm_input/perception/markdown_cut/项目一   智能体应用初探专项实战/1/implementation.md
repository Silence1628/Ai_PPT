### 【任务实施】
本任务会带领学员在RAGFlow平台中实现一个可交互的智能问答应用。并建立评估体系，评价智能问答系统回复的质量，并依此调整工作流，不断优化。
##### 一、熟悉RAGFlow平台并创建基础应用
步骤一：创建应用并进入工作流编排。
进入RAGFlow平台，在上方菜单栏中选择“智能体”，如果还未创建智能体应用，会如下图 1-1- 9所示，此时点击加号创建一个智能体应用，在弹出窗口中选择“智能体流程”类型，命名为“我的第一个智能体工作流”。进入工作流画布，此时系统已自动生成开始节点，默认的工作类型是对话式。如果不是，可以根据图 1-1- 10所示的点击顺序修改工作类型。
图  创建第一个智能体工作流
图  切换开始节点为会话模式
步骤二：配置LLM节点。
图 1-1- 11添加大模型节点
如图 ，将鼠标光标放在开始模块处，模块右边会出现加号，点击这个符号弹出节点库列表，从中选择“智能体”节点，在RAGFlow中，大模型节点被称作智能体，但我们实际知道该节点承担的作用是整个工作流的“大脑”，因此在后文中不论提及“智能体节点”还是“大模型节点”都是指向这个节点。该模块会自动连接到开始模块的尾端，并将其摆放在适合位置。在该节点中完成三件事：选择模型、编写系统提示词以及配置模型参数。点击箭头①处的智能体节点，可以弹出如图 右边所示的模块详情标签，点击箭头②处的模型栏目，会弹出模型配置的标签。在③处可以选择接入工作流的大模型；在方框④处可以配置模型输出的部分参数。在大模型的参数列表中，我们需要关注的参数有三个：
① 温度（temperature）：用于控制随机性和多样性的程度。较高的 temperature 值会降低概率分布的峰值，使得更多的低概率词被选择，生成结果更加多样化；而较低的 temperature 值则会增强概率分布的峰值，使得高概率词更容易被选择，生成结果更加确定。
② 最大标记（或作最大token）：用于指定模型在生成内容时 token 的最大数量，它定义了生成的上限。
③ Top P：生成过程中核采样方法概率阈值，例如，取值为 0.8 时，仅保留概率加起来大于等于 0.8 的最可能 token 的最小集合作为候选集。取值范围为（0,1.0)，取值越大，生成的随机性越高；取值越低，生成的确定性越高。
初次使用该部分内容均采用图 1-1- 12的默认配置即可完成任务实施。
图  配置大模型及参数
在箭头②处模型选择框的下方，我们可以编写系统提示词，按照结构化格式设定智能体的角色、任务边界、输出要求，以至于获得更好的回复和工作处理。当然在本节任务中，我们仅需要实现一个最小的智能体对话工作流，因此编写系统提示词可以省略，观察并使用默认的提示词即可。在后面的练习中我们会更加详细地介绍这部分内容。
步骤三：关联用户输入。
点击智能体节点，如图 箭头①所示，在系统提示词的下方有用户提示词表单，点击右上角的变量符号（箭头②处），可快速插入变量。将开始节点传递的用户问题变量（通常为sys.query）填入，确保模型能够接收到用户的问题。在默认配置中sys.query变量已经填入用户提示词，如果还需添加其他变量，可按照该流程操作。
图  关联用户输入
步骤四：连接结束节点并发布。
按照和第二步一样的方式，如图 点击智能体节点右边的加号，在弹出页中选择回复消息，创建一个流程结束节点。同样点击这个节点模块，在弹出的标签中，点击箭头②所示的变量图标，将智能体输出的内容添加到消息窗口中。

##### 二、编写初版系统提示词并建立基础评估指标
在对话框中输入任意问题，如“介绍一下什么是智能体”，系统将调用大模型生成符合预期的回答，并在界面中返回结果。可以通过人工评估输出质量，不断优化提示问题和参数，直到满足要求。本节会带领学员学会从输出结果中反推应用问题，并建立基本的评价标准，而不是凭感觉判断“好不好”。
现在回到智能体节点，修改系统提示词如图 ：“你是一个AI助手，请回答用户关于智能门锁的问题。”这是一个最简单的提示词，在下文中我们会称为V1版提示词。
图  配置大模型的系统提示词

##### 三、提示词基础优化
通过客观记录V1版Prompt的表现，我们发现了它存在的问题并建立了优化的基准，大家可以针对刚才发现的问题，增加关键约束，将提示词从基本可用的V1版更新为基础可控的V2版。可以参考下方的V2提示词样例：
```
你是一名智能门锁企业的售后支持助手，负责处理用户在安装、联网、故障排查和售后服务中的咨询。
回答要求：
1. 优先围绕用户当前问题给出处理建议；
2. 如果信息不足，不要直接下结论，应先提醒用户补充关键信息；
3. 不要编造产品参数、维修政策或售后流程；
4. 语气要专业、耐心、简洁；
5. 输出时尽量分点说明。
```
