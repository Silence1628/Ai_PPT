# 任务二   提示词工程

### 【任务描述】
本章旨在帮助学员建立提示词工程的基础认知，理解提示词在智能体系统中的核心作用，掌握提示词工程的基本目标、基本原理和基本工作环境。通过本章学习，学员将认识到：提示词并不是对模型“随口一说”，而是对 智能体行为边界、推理路径和输出形式的显式设计。本章旨在帮助学员建立提示词工程的基础认知，理解提示词在智能体系统中的核心作用，掌握提示词工程的基本目标、基本原理和基本工作环境。通过本章学习，学员将认识到：提示词并不是对模型“随口一说”，而是对 智能体行为边界、推理路径和输出形式的显式设计。
### 【任务能力目标】
能从智能体系统设计视角理解提示词的价值，建立“提示词即行为设计”的意识；
能围绕确定性、逻辑性、效率三个维度分析一个提示词是否优质；
能使用RAGFlow工作流开展提示词测试、记录和迭代优化；
能根据具体场景判断如何构建提示词信息，约束智能体给出符合场景需求的输出内容。
### 【任务重难点】
重点；理解提示词如何影响智能体的决策过程与输出稳定性。
难点；从“大模型会生成文字”过渡到“提示词在塑造模型行为”这一系统化认知。
### 【任务小结】
在本任务中，解决的是提示词工程的认知起点问题。完成任务后，学员应当意识到：提示词并不是模型交互中的附属品，而是 Agent 行为设计的核心入口。它决定了模型如何理解任务、如何分配注意力、如何组织推理、如何控制输出。提示词工程的目标不是把话说得更华丽，而是把要求说得更明确、更稳定、更高效。
只有理解了这一点，后续关于结构化 Prompt、Few-Shot、工具调用、规划与反思等技术，才有真正落地的基础。
