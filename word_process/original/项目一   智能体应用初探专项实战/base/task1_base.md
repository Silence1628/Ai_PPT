# 任务一   设计并实现智能体工作流

### 【任务描述】
本任务旨在指导学员完成基于RAGFlow平台的智能问答助手搭建任务，并在项目中辨析智能体与工作流的概念，掌握二者的核心能力框架以及实际应用开发流程。学员将学习如何使用RAGFlow的可视化工作流和提示词工程方法，构建一个具备基础对话能力的AI应用。本任务旨在指导学员完成基于RAGFlow平台的智能问答助手搭建任务，并在项目中辨析智能体与工作流的概念，掌握二者的核心能力框架以及实际应用开发流程。学员将学习如何使用RAGFlow的可视化工作流和提示词工程方法，构建一个具备基础对话能力的AI应用。
### 【任务能力目标】
能准确区分智能体与工作流的适用场景，并能根据任务特征做出合理的技术选型和搭配；
能根据实际场景编写有效的系统提示词，完成一个可交互的智能问答应用，并调整提示词和参数优化智能体，观察并记录模型输出稳定性的变化；
能认识到AI技术赋能传统产业升级的现实价值，具备开阔的技术视野和灵活的学习态度，主动思考如何将所学技能服务于国家智能制造与数字化转型战略。
### 【任务重难点】
重点；掌握有效的系统提示词编写方法。
难点；理解改变提示词和参数对模型输出的影响
### 【任务小结】
通过本任务，我们不仅能够完成一个基础智能问答助手的搭建，更重要的是理解：智能体开发并不是简单地“调用一个模型”，而是围绕业务目标进行场景设定、工作流搭建、提示词配置、测试验证和持续改进的过程。
本章首先把“最小可运行应用”搭起来，再通过评估指标发现应用在准确性、稳定性、边界感和可用性等方面的不足。这样一来，下一章关于提示词工程的学习就有了明确的问题导向和真实需求背景。两章结合，才能构成一个完整的智能体实训学习闭环。
