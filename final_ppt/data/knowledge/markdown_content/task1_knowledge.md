## 编码器与解码器

### 1.编码器（Encoder）

编码器的主要任务是将输入文本转换为一种语义丰富的向量表示 。这个表示不仅包含每个词本身的含义，还融合了上下文信息，帮助模型理解句子的整体意思。

例如，输入一句话：“我喜欢自然语言处理。”，编码器会将这句话中的每一个词都转化为一个高维向量，并通过多层网络提取出它们之间的关系，最终形成一个完整的语义表达。

编码器由多个相同的层堆叠而成，每一层包括两个核心组件：

#### 自注意力机制（Self-Attention）

##### 前馈神经网络（Feed-Forward Network）

这种结构使得编码器能够从不同角度去分析输入内容，从而获得更全面的理解。

#### 2.解码器（Decoder）

解码器的任务是根据编码器输出的语义表示，逐步生成目标序列 。这个目标序列可以是翻译后的句子、问答的答案，甚至是续写的一段文字。

举个例子：如果你问模型“什么是人工智能？”，编码器会先理解这个问题，然后解码器会一步步地生成答案，如：“人工智能是一种……”。

解码器同样由多个相同层堆叠而成，每一层包括三个关键组件：

##### 掩码自注意力机制（Masked Self-Attention） ：防止提前看到未来的信息；

###### 交叉注意力机制（Cross-Attention） ：连接编码器的输出；

####### 前馈神经网络（Feed-Forward Network）

这样的设计让解码器既能关注当前已生成的内容，又能参考原始输入的信息，确保生成结果准确且连贯。

###### 3.编码器与解码器的关系

两者之间通过交叉注意力机制紧密联系，使得解码器在生成每一个词时，都能参考整个输入序列的信息。这种协同工作机制，是Transformer模型实现高效语言建模的关键，如图 1-1-2所示。

## 注意力机制

### （一）注意力机制的类型

### 自注意力机制（Self-Attention）

### 应用场景：编码器内部

### 作用：帮助模型理解输入序列内部的语义结构

### 交叉注意力机制（Cross-Attention）

### 应用场景：解码器中

### 作用：连接编码器输出与解码器输入，实现跨序列的信息融合

### 多头注意力机制（Multi-Head Attention）

### 应用场景：广泛应用于编码器和解码器中

### 作用：提升模型表达能力和泛化能力

### （二）注意力机制的本质

### Query（查询） ：就是你的问题卡片，代表你现在想知道什么；

### Key（键） ：是每本书的标签或标题，告诉你这本书讲的是什么内容；

### Value（值） ：是这本书的实际内容，是你真正想获取的信息。

### 模型会把“看”当作Query；

### 把“小明”、“在”、“图书馆”、“书”等词都当作Key；

### 然后找出哪些词和“看”关系最密切，例如“小明”和“书”；

### 再从这些词对应的Value中提取信息；

### 最终得出：“看”是一个动作，是由“小明”发出的，对象是“书”。

### （三）注意力机制的计算流程

### 输入向量化

### [0.6, 0.4, -0.5] ]  // 老鼠

这些向量构成了模型处理的基础数据。

#### 生成 Query、Key、Value 向量

接下来，每个词的向量会分别乘以三个不同的可学习权重矩阵，得到对应的 Query（Q）、Key（K）、Value（V） 向量：

Q = X * W_Q

K = X * W_K

V = X * W_V

其中：

X 是输入词向量；

W_Q、W_K、W_V 是三个可训练参数矩阵；

### Q、K、V 分别是查询向量、键向量和值向量。

这一步相当于给每个词分配了一个“问题视角（Q）”、“标签视角（K）”和“内容视角（V）”。

#### 计算注意力得分（Attention Score）

通过 Query 和 Key 做点积运算，再除以一个缩放因子 sqrt(d_k)，防止点积结果过大导致梯度不稳定。

Attention Score = (Q * K.T) / sqrt(d_k)

说明：

Q * K.T 表示 Q 和 K 的转置相乘，得到一个相关性矩阵；

d_k 是 Q 和 K 的维度（如 64）；

结果是一个注意力得分矩阵，表示每个词与其他词的相关程度。

##### Softmax 归一化

对每一行进行 Softmax 操作，把注意力得分变成概率分布（即注意力权重）：

Attention Weights = Softmax( (Q * K.T) / sqrt(d_k) )

这个权重越高，说明对应位置的词越重要。

###### 加权求和 Value 向量

最后，用这些注意力权重去加权求和 Value 向量，得到最终的输出：

Output = Attention Weights * V

这样我们就得到了一个新的词向量，它不仅包含了这个词本身的含义，还融合了句中其他相关词的信息。

####### 多头注意力机制（Multi-Head Attention）

前面讲的是单个注意力头（Single Head）的情况。而在实际应用中，Transformer 使用的是多头注意力机制 ，即并行运行多个注意力模块，然后将它们的结果拼接起来：

head_1 = Softmax( (Q1*K1.T)/sqrt(d_k) ) * V1

head_2 = Softmax( (Q2*K2.T)/sqrt(d_k) ) * V2

...

head_h = Softmax( (Qh*Kh.T)/sqrt(d_k) ) * Vh

MultiHead Output = Concat(head_1, head_2, ..., head_h) * W_O

其中：

每个 head 是一个独立的注意力头；

Concat 表示拼接操作；

W_O 是最终的线性变换矩阵。

这种设计让模型可以从不同角度捕捉信息，提升理解和表达能力。
